# Chronly v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build v1 of Chronly — an open-source, privacy-first Chrome + Firefox browser extension providing a New Tab clock dashboard and toolbar popup control center with world clocks, alarms, timer/stopwatch, and Pomodoro, built on a Manifest V3 architecture that is provably reliable across service-worker suspension, browser restart, and system sleep/wake.

**Architecture:** A framework-agnostic `lib/core/` module (types, storage, timezone math, scheduler state machine, calendar export, notification specs, audio) holds every rule that must be unit-tested and correct. The `entrypoints/background.ts` service worker is a thin orchestrator: one durable `alarms` API entry wakes it every 30s, it reads due records from storage via `lib/core`, and fires notifications/audio/state updates. The popup and New Tab entrypoints are Svelte UIs that read and write the *same* `chrome.storage` records directly through the Task 3 store classes — no custom runtime-messaging protocol between them and the background worker, since any extension context can access storage equally. They never hold their own authoritative timer state, only a foreground render loop that re-derives display time from persisted absolute timestamps.

**Tech Stack:** WXT (Vite-based web extension framework) + Svelte + TypeScript, Vitest for unit tests, Playwright for e2e smoke tests, GitHub Actions for CI, npm as the package manager.

Full design rationale and competitive research: `docs/superpowers/specs/2026-08-03-chronly-clock-extension-design.md`.

## Global Constraints

- Manifest V3, targeting Chrome/Chromium and Firefox from a single WXT codebase.
- Package manager: npm (zero extra install for any contributor with Node.js).
- No AI/Claude/Anthropic mentions anywhere — not in code comments, commit messages, README, docs, or UI copy. Commits in this repo must NOT include a "Co-Authored-By: Claude" trailer.
- No telemetry, analytics, or account system of any kind.
- License: MIT (`LICENSE` file at repo root).
- No bundled/static tzdata — all timezone math uses the native `Intl` API only.
- Every timer/alarm/Pomodoro session is persisted as a record with an absolute target epoch-ms timestamp; nothing relies on `setTimeout`/`setInterval` surviving inside the background service worker.
- Exactly one durable `browser.alarms` entry (name `"tick"`, `periodInMinutes: 0.5`) drives all scheduling — never one alarm per user timer/record.
- Alarm firing is redundant: audio + OS notification together, with an optional full-tab takeover for alarms specifically.
- No artificial caps: unlimited world clocks, alarms, timers, and Pomodoro history.
- New Tab dashboard stays clock-focused in v1: no weather, quotes, or to-do widgets.
- Calendar integration in v1 is export-only (Google Calendar link + `.ics` download) — no OAuth, no new permission. Two-way sync is out of scope for this plan (tracked in the spec's roadmap).
- All access to the `browser` runtime API is an explicit `import { browser } from 'wxt/browser'` — never WXT's auto-imported global — so any contributor can trace where it comes from. The one exception is WXT's own entrypoint-definition helpers (`defineBackground`, etc.), which use WXT's standard auto-import since that's idiomatic WXT and expected by anyone who has used the framework before.
- Firefox MV3 requires the `--mv3` flag on every `wxt`/`wxt build`/`wxt zip` invocation targeting `-b firefox` (WXT defaults Firefox to MV2 otherwise).
- All async storage/browser-API access goes through the abstractions defined in Task 3 (`StorageBackend`, `RecordStore`, `SettingsStore`, `WorldClockStore`) — UI and background code never call `browser.storage.*` directly.

```typescript
import type { SchedulableRecord, Settings, WorldClockEntry } from './types'
import { DEFAULT_SETTINGS } from './types'

export interface StorageBackend {
  get<T>(key: string): Promise<T | undefined>
  set<T>(key: string, value: T): Promise<void>
  remove(key: string): Promise<void>
}

export function createMemoryStorageBackend(): StorageBackend {
  const map = new Map<string, unknown>()
  return {
    async get<T>(key: string) {
      return map.get(key) as T | undefined
    },
    async set<T>(key: string, value: T) {
      map.set(key, value)
    },
    async remove(key: string) {
      map.delete(key)
    },
  }
}

const RECORDS_KEY = 'records'
const WORLD_CLOCKS_KEY = 'worldClocks'
const SETTINGS_KEY = 'settings'

export class RecordStore {
  constructor(private backend: StorageBackend) {}

  async getAll(): Promise<SchedulableRecord[]> {
    const map = await this.backend.get<Record<string, SchedulableRecord>>(RECORDS_KEY)
    return map ? Object.values(map) : []
  }

  async get(id: string): Promise<SchedulableRecord | undefined> {
    const map = await this.backend.get<Record<string, SchedulableRecord>>(RECORDS_KEY)
    return map?.[id]
  }

  async upsert(record: SchedulableRecord): Promise<void> {
    const map = (await this.backend.get<Record<string, SchedulableRecord>>(RECORDS_KEY)) ?? {}
    map[record.id] = record
    await this.backend.set(RECORDS_KEY, map)
  }

  async remove(id: string): Promise<void> {
    const map = (await this.backend.get<Record<string, SchedulableRecord>>(RECORDS_KEY)) ?? {}
    delete map[id]
    await this.backend.set(RECORDS_KEY, map)
  }
}

export class WorldClockStore {
  constructor(private backend: StorageBackend) {}

  async getAll(): Promise<WorldClockEntry[]> {
    const list = await this.backend.get<WorldClockEntry[]>(WORLD_CLOCKS_KEY)
    return (list ?? []).slice().sort((a, b) => a.order - b.order)
  }

  async upsert(entry: WorldClockEntry): Promise<void> {
    const list = (await this.backend.get<WorldClockEntry[]>(WORLD_CLOCKS_KEY)) ?? []
    const idx = list.findIndex((e) => e.id === entry.id)
    if (idx === -1) list.push(entry)
    else list[idx] = entry
    await this.backend.set(WORLD_CLOCKS_KEY, list)
  }

  async remove(id: string): Promise<void> {
    const list = (await this.backend.get<WorldClockEntry[]>(WORLD_CLOCKS_KEY)) ?? []
    await this.backend.set(
      WORLD_CLOCKS_KEY,
      list.filter((e) => e.id !== id),
    )
  }

  async reorder(orderedIds: string[]): Promise<void> {
    const list = (await this.backend.get<WorldClockEntry[]>(WORLD_CLOCKS_KEY)) ?? []
    const byId = new Map(list.map((e) => [e.id, e]))
    const reordered = orderedIds
      .map((id, index) => {
        const entry = byId.get(id)
        return entry ? { ...entry, order: index } : undefined
      })
      .filter((e): e is WorldClockEntry => e !== undefined)
    await this.backend.set(WORLD_CLOCKS_KEY, reordered)
  }
}

export class SettingsStore {
  constructor(private backend: StorageBackend) {}

  async get(): Promise<Settings> {
    const stored = await this.backend.get<Settings>(SETTINGS_KEY)
    return { ...DEFAULT_SETTINGS, ...stored }
  }

  async update(patch: Partial<Settings>): Promise<Settings> {
    const current = await this.get()
    const next = { ...current, ...patch }
    await this.backend.set(SETTINGS_KEY, next)
    return next
  }
}
```

```typescript
import { browser } from 'wxt/browser'

export function createExtensionStorageBackend(area: 'local' | 'sync'): StorageBackend {
  const storageArea = browser.storage[area]
  return {
    async get<T>(key: string) {
      const result = await storageArea.get(key)
      return result[key] as T | undefined
    },
    async set<T>(key: string, value: T) {
      await storageArea.set({ [key]: value })
    },
    async remove(key: string) {
      await storageArea.remove(key)
    },
  }
}
```

```typescript
export function formatTimeInZone(
  date: Date,
  timeZone: string,
  opts: { hour12: boolean; showSeconds: boolean },
): string {
  const formatter = new Intl.DateTimeFormat('en-GB', {
    timeZone,
    hour12: opts.hour12,
    hour: '2-digit',
    minute: '2-digit',
    second: opts.showSeconds ? '2-digit' : undefined,
  })
  return formatter.format(date)
}

export function getUtcOffsetMinutes(timeZone: string, at: Date): number {
  const parts = new Intl.DateTimeFormat('en-US', { timeZone, timeZoneName: 'shortOffset' }).formatToParts(at)
  const raw = parts.find((p) => p.type === 'timeZoneName')?.value ?? 'GMT+0'
  const match = /GMT([+-])(\d{1,2})(?::?(\d{2}))?/.exec(raw)
  if (!match) return 0
  const sign = match[1] === '-' ? -1 : 1
  const hours = Number(match[2])
  const minutes = Number(match[3] ?? '0')
  return sign * (hours * 60 + minutes)
}

export function formatUtcOffsetLabel(offsetMinutes: number): string {
  const sign = offsetMinutes >= 0 ? '+' : '-'
  const abs = Math.abs(offsetMinutes)
  const hours = Math.floor(abs / 60)
  const minutes = abs % 60
  return `UTC${sign}${hours}${minutes ? ':' + String(minutes).padStart(2, '0') : ''}`
}

function zonedDateKey(date: Date, timeZone: string): string {
  return new Intl.DateTimeFormat('en-CA', { timeZone, year: 'numeric', month: '2-digit', day: '2-digit' }).format(date)
}

export function getDayOffset(baseZone: string, targetZone: string, at: Date): number {
  const baseDate = new Date(zonedDateKey(at, baseZone) + 'T00:00:00Z')
  const targetDate = new Date(zonedDateKey(at, targetZone) + 'T00:00:00Z')
  return Math.round((targetDate.getTime() - baseDate.getTime()) / 86_400_000)
}

export function getRelativeDiffLabel(baseZone: string, targetZone: string, at: Date): string {
  const diffMinutes = getUtcOffsetMinutes(targetZone, at) - getUtcOffsetMinutes(baseZone, at)
  const sign = diffMinutes >= 0 ? '+' : '-'
  const abs = Math.abs(diffMinutes)
  const hours = Math.floor(abs / 60)
  const minutes = abs % 60
  const hoursLabel = `${sign}${hours}h${minutes ? minutes + 'm' : ''}`
  const dayOffset = getDayOffset(baseZone, targetZone, at)
  const dayLabel =
    dayOffset === 0 ? 'today' : dayOffset === 1 ? 'tomorrow' : dayOffset === -1 ? 'yesterday' : dayOffset > 0 ? `${dayOffset} days ahead` : `${Math.abs(dayOffset)} days behind`
  return `${hoursLabel}, ${dayLabel}`
}

/**
 * Finds the UTC instant whose local representation in `timeZone` matches the given wall-clock
 * components, correcting for that zone's offset via fixed-point iteration (handles DST).
 */
export function zonedWallTimeToInstant(
  timeZone: string,
  year: number,
  month: number,
  day: number,
  hour: number,
  minute: number,
): Date {
  let guess = Date.UTC(year, month - 1, day, hour, minute)
  for (let i = 0; i < 3; i++) {
    const offset = getUtcOffsetMinutes(timeZone, new Date(guess))
    const corrected = Date.UTC(year, month - 1, day, hour, minute) - offset * 60_000
    if (corrected === guess) break
    guess = corrected
  }
  return new Date(guess)
}
```

```typescript
import type { AlarmRecord, AlarmRecurrence, CountdownRecord, PomodoroConfig, PomodoroRecord, SchedulableRecord } from './types'

let idCounter = 0

export function generateId(prefix: string): string {
  idCounter += 1
  return `${prefix}-${Date.now()}-${idCounter}`
}

export function isDue(record: SchedulableRecord, now: number): boolean {
  if (record.notified) return false
  if ((record.kind === 'countdown' || record.kind === 'pomodoro') && record.status !== 'running') return false
  return record.targetTimestamp <= now
}

export function computeDueRecords(records: SchedulableRecord[], now: number): SchedulableRecord[] {
  return records.filter((r) => isDue(r, now))
}

export function markNotified(record: SchedulableRecord, now: number): SchedulableRecord {
  return { ...record, notified: true, updatedAt: now }
}

export function computeNextAlarmOccurrence(record: AlarmRecord, after: number): number | null {
  if (!record.recurrence || record.recurrence.days.length === 0) return null
  const target = new Date(record.targetTimestamp)
  const hours = target.getHours()
  const minutes = target.getMinutes()
  let candidate = new Date(after)
  candidate.setHours(hours, minutes, 0, 0)
  for (let i = 0; i < 8; i++) {
    if (candidate.getTime() > after && record.recurrence.days.includes(candidate.getDay())) {
      return candidate.getTime()
    }
    candidate = new Date(candidate.getTime() + 86_400_000)
    candidate.setHours(hours, minutes, 0, 0)
  }
  return null
}

export function advancePomodoroPhase(record: PomodoroRecord, now: number): PomodoroRecord {
  const nextCycleCount = record.phase === 'focus' ? record.cycleCount + 1 : record.cycleCount
  const nextPhase: PomodoroRecord['phase'] =
    record.phase === 'focus' ? (nextCycleCount % record.config.cyclesBeforeLongBreak === 0 ? 'longBreak' : 'shortBreak') : 'focus'
  const duration =
    nextPhase === 'focus' ? record.config.focusMs : nextPhase === 'shortBreak' ? record.config.shortBreakMs : record.config.longBreakMs
  return {
    ...record,
    phase: nextPhase,
    cycleCount: nextCycleCount,
    targetTimestamp: now + duration,
    status: 'running',
    notified: false,
    remainingMsAtPause: null,
    updatedAt: now,
  }
}

export function reconcileFiredRecord(record: SchedulableRecord, now: number): SchedulableRecord {
  const notified = markNotified(record, now)
  if (notified.kind === 'alarm') {
    const next = computeNextAlarmOccurrence(notified, now)
    if (next === null) return notified // one-off: stays in storage, notified=true, until dismissed or snoozed
    return { ...notified, targetTimestamp: next, notified: false, updatedAt: now }
  }
  if (notified.kind === 'countdown') {
    return { ...notified, status: 'completed', updatedAt: now }
  }
  return advancePomodoroPhase(notified, now)
}

export function createCountdown(
  label: string,
  durationMs: number,
  now: number,
  opts: Partial<Pick<CountdownRecord, 'soundId' | 'volume'>> = {},
): CountdownRecord {
  return {
    id: generateId('countdown'),
    kind: 'countdown',
    label,
    durationMs,
    targetTimestamp: now + durationMs,
    status: 'running',
    remainingMsAtPause: null,
    soundId: opts.soundId ?? 'default',
    volume: opts.volume ?? 0.8,
    notified: false,
    createdAt: now,
    updatedAt: now,
  }
}

export function createAlarm(
  label: string,
  targetTimestamp: number,
  now: number,
  recurrence: AlarmRecurrence | null = null,
  opts: Partial<Pick<AlarmRecord, 'soundId' | 'volume' | 'fullScreenTakeover'>> = {},
): AlarmRecord {
  return {
    id: generateId('alarm'),
    kind: 'alarm',
    label,
    targetTimestamp,
    recurrence,
    fullScreenTakeover: opts.fullScreenTakeover ?? false,
    soundId: opts.soundId ?? 'default',
    volume: opts.volume ?? 0.8,
    notified: false,
    createdAt: now,
    updatedAt: now,
  }
}

export function createPomodoro(
  label: string,
  config: PomodoroConfig,
  now: number,
  opts: Partial<Pick<PomodoroRecord, 'soundId' | 'volume'>> = {},
): PomodoroRecord {
  return {
    id: generateId('pomodoro'),
    kind: 'pomodoro',
    label,
    phase: 'focus',
    cycleCount: 0,
    config,
    targetTimestamp: now + config.focusMs,
    status: 'running',
    remainingMsAtPause: null,
    soundId: opts.soundId ?? 'default',
    volume: opts.volume ?? 0.8,
    notified: false,
    createdAt: now,
    updatedAt: now,
  }
}

export function pauseRecord<T extends CountdownRecord | PomodoroRecord>(record: T, now: number): T {
  if (record.status !== 'running') return record
  return { ...record, status: 'paused', remainingMsAtPause: record.targetTimestamp - now, updatedAt: now }
}

export function resumeRecord<T extends CountdownRecord | PomodoroRecord>(record: T, now: number): T {
  if (record.status !== 'paused' || record.remainingMsAtPause === null) return record
  return { ...record, status: 'running', targetTimestamp: now + record.remainingMsAtPause, remainingMsAtPause: null, updatedAt: now }
}
```

```typescript
export interface CalendarEvent {
  title: string
  start: Date
  end: Date
  description?: string
}

function toIcsDate(date: Date): string {
  return date.toISOString().replace(/[-:]/g, '').split('.')[0] + 'Z'
}

export function buildGoogleCalendarLink(event: CalendarEvent): string {
  const params = new URLSearchParams({
    action: 'TEMPLATE',
    text: event.title,
    dates: `${toIcsDate(event.start)}/${toIcsDate(event.end)}`,
    details: event.description ?? '',
  })
  return `https://calendar.google.com/calendar/render?${params.toString()}`
}

export function buildIcs(event: CalendarEvent): string {
  const lines = [
    'BEGIN:VCALENDAR',
    'VERSION:2.0',
    'PRODID:-//Chronly//Chronly Extension//EN',
    'BEGIN:VEVENT',
    `UID:${crypto.randomUUID()}`,
    `DTSTAMP:${toIcsDate(new Date())}`,
    `DTSTART:${toIcsDate(event.start)}`,
    `DTEND:${toIcsDate(event.end)}`,
    `SUMMARY:${event.title.replace(/\r?\n/g, '\\n')}`,
    event.description ? `DESCRIPTION:${event.description.replace(/\r?\n/g, '\\n')}` : undefined,
    'END:VEVENT',
    'END:VCALENDAR',
  ].filter((line): line is string => line !== undefined)
  return lines.join('\r\n')
}
```

```typescript
import { browser } from 'wxt/browser'

export interface SoundPreset {
  id: string
  label: string
  frequency: number
  beeps: number
}

export const SOUND_PRESETS: SoundPreset[] = [
  { id: 'default', label: 'Classic beep', frequency: 880, beeps: 3 },
  { id: 'gentle', label: 'Gentle chime', frequency: 523, beeps: 2 },
  { id: 'urgent', label: 'Urgent alert', frequency: 1046, beeps: 5 },
]

export function resolveSoundPreset(soundId: string): SoundPreset {
  return SOUND_PRESETS.find((p) => p.id === soundId) ?? SOUND_PRESETS[0]
}

export interface PlaySoundMessage {
  target: 'offscreen'
  type: 'play-sound'
  soundId: string
  volume: number
}

export function buildPlaySoundMessage(soundId: string, volume: number): PlaySoundMessage {
  return { target: 'offscreen', type: 'play-sound', soundId, volume }
}

const OFFSCREEN_URL = '/offscreen.html'

async function ensureOffscreenDocument(): Promise<void> {
  const contexts = await browser.runtime.getContexts({ contextTypes: ['OFFSCREEN_DOCUMENT'] })
  if (contexts.length > 0) return
  await browser.offscreen.createDocument({
    url: OFFSCREEN_URL,
    reasons: ['AUDIO_PLAYBACK'],
    justification: 'Play the selected alarm/timer sound when it fires.',
  })
}

function playTone(frequency: number, volume: number, durationMs: number): Promise<void> {
  return new Promise((resolve) => {
    const context = new AudioContext()
    const oscillator = context.createOscillator()
    const gain = context.createGain()
    oscillator.frequency.value = frequency
    gain.gain.value = volume
    oscillator.connect(gain)
    gain.connect(context.destination)
    oscillator.start()
    oscillator.stop(context.currentTime + durationMs / 1000)
    oscillator.onended = () => {
      void context.close()
      resolve()
    }
  })
}

export async function playPresetLocally(soundId: string, volume: number): Promise<void> {
  const preset = resolveSoundPreset(soundId)
  for (let i = 0; i < preset.beeps; i++) {
    await playTone(preset.frequency, volume, 250)
    await new Promise((resolve) => setTimeout(resolve, 150))
  }
}

export async function playAlarmSound(soundId: string, volume: number): Promise<void> {
  if ('offscreen' in browser) {
    await ensureOffscreenDocument()
    await browser.runtime.sendMessage(buildPlaySoundMessage(soundId, volume))
    return
  }
  if (typeof AudioContext !== 'undefined') {
    await playPresetLocally(soundId, volume)
  }
}
```

```typescript
import { browser } from 'wxt/browser'
import { playAlarmSound } from '../lib/core/audio'
import { buildNotificationSpec, showNotification } from '../lib/core/notifications'
import { computeDueRecords, pauseRecord, reconcileFiredRecord } from '../lib/core/scheduler'
import { createExtensionStorageBackend, RecordStore } from '../lib/core/storage'
import type { SchedulableRecord } from '../lib/core/types'

export const TICK_ALARM_NAME = 'tick'
export const TICK_PERIOD_MINUTES = 0.5

export async function ensureTickAlarm(): Promise<void> {
  const existing = await browser.alarms.get(TICK_ALARM_NAME)
  if (existing) return
  await browser.alarms.create(TICK_ALARM_NAME, { periodInMinutes: TICK_PERIOD_MINUTES })
}

async function fireRecord(record: SchedulableRecord): Promise<void> {
  await showNotification(buildNotificationSpec(record))
  await playAlarmSound(record.soundId, record.volume)
}

export async function reconcileDueRecords(store: RecordStore, now: number): Promise<void> {
  const due = computeDueRecords(await store.getAll(), now)
  for (const record of due) {
    await fireRecord(record)
    await store.upsert(reconcileFiredRecord(record, now))
  }
}

export function extractRecordId(notificationId: string): string {
  return notificationId.replace(/^chronly-(alarm|countdown|pomodoro)-/, '')
}

function isTransient(record: SchedulableRecord): boolean {
  return (record.kind === 'alarm' && record.recurrence === null) || (record.kind === 'countdown' && record.status === 'completed')
}

export async function handleNotificationButton(
  store: RecordStore,
  notificationId: string,
  buttonIndex: number,
  now: number,
): Promise<void> {
  const record = await store.get(extractRecordId(notificationId))
  if (!record) return
  if (record.kind === 'alarm' && buttonIndex === 0) {
    // Snooze 5 minutes.
    await store.upsert({ ...record, targetTimestamp: now + 5 * 60_000, notified: false, updatedAt: now })
    await browser.notifications.clear(notificationId)
    return
  }
  if (record.kind === 'pomodoro' && buttonIndex === 0) {
    // Pause the phase that already auto-started.
    await store.upsert(pauseRecord(record, now))
    await browser.notifications.clear(notificationId)
    return
  }
  if (isTransient(record)) await store.remove(record.id)
  await browser.notifications.clear(notificationId)
}

export async function handleNotificationClosed(store: RecordStore, notificationId: string): Promise<void> {
  const record = await store.get(extractRecordId(notificationId))
  if (record && isTransient(record)) await store.remove(record.id)
}

export default defineBackground(() => {
  const store = new RecordStore(createExtensionStorageBackend('local'))

  browser.alarms.onAlarm.addListener((alarm) => {
    if (alarm.name !== TICK_ALARM_NAME) return
    void reconcileDueRecords(store, Date.now())
  })

  browser.notifications.onButtonClicked.addListener((notificationId, buttonIndex) => {
    void handleNotificationButton(store, notificationId, buttonIndex, Date.now())
  })

  browser.notifications.onClosed.addListener((notificationId) => {
    void handleNotificationClosed(store, notificationId)
  })

  browser.runtime.onInstalled.addListener(() => {
    void ensureTickAlarm()
  })

  browser.runtime.onStartup.addListener(() => {
    void ensureTickAlarm()
  })

  // Covers the case where the worker restarts mid-session without a fresh onInstalled/onStartup event.
  void ensureTickAlarm()
})
```

```typescript
export function watchStorageKey<T>(key: string, onChange: (value: T | undefined) => void): () => void {
  const listener = (changes: Record<string, { newValue?: unknown; oldValue?: unknown }>, areaName: string) => {
    if (areaName !== 'local' && areaName !== 'sync') return
    if (key in changes) onChange(changes[key].newValue as T | undefined)
  }
  browser.storage.onChanged.addListener(listener)
  return () => browser.storage.onChanged.removeListener(listener)
}
```

```typescript
export function createNowStore(intervalMs = 250) {
  return readable(Date.now(), (set) => {
```

```typescript
// Alarms fire by device-local wall-clock time (not a saved timezone) — the same assumption
// a phone's alarm clock makes, and what "set an alarm for 7am" means to a user.
export function nextOccurrence(hour: number, minute: number, now: number): number {
  const candidate = new Date(now)
  candidate.setHours(hour, minute, 0, 0)
  if (candidate.getTime() <= now) candidate.setDate(candidate.getDate() + 1)
  return candidate.getTime()
}
```

```typescript
import type { StopwatchState } from './types'

export function computeElapsedMs(state: StopwatchState, now: number): number {
  if (state.status === 'running' && state.startedAt !== null) {
    return state.elapsedMsBeforeStart + (now - state.startedAt)
  }
  return state.elapsedMsBeforeStart
}

export function startStopwatch(state: StopwatchState, now: number): StopwatchState {
  if (state.status === 'running') return state
  return { ...state, status: 'running', startedAt: now }
}

export function pauseStopwatch(state: StopwatchState, now: number): StopwatchState {
  if (state.status !== 'running') return state
  return { ...state, status: 'paused', elapsedMsBeforeStart: computeElapsedMs(state, now), startedAt: null }
}

export function resetStopwatch(): StopwatchState {
  return { status: 'idle', startedAt: null, elapsedMsBeforeStart: 0, laps: [] }
}

export function recordLap(state: StopwatchState, now: number): StopwatchState {
  return { ...state, laps: [computeElapsedMs(state, now), ...state.laps] }
}
```

```svelte
<script lang="ts">
  import {
    formatTimeInZone,
    formatUtcOffsetLabel,
    getRelativeDiffLabel,
    getUtcOffsetMinutes,
    zonedWallTimeToInstant,
  } from '../lib/core/time'
  import { createNowStore } from '../lib/ui/now'
  import { worldClockActions, worldClocks } from '../lib/ui/worldClocks'

  const now = createNowStore()
  const localZone = Intl.DateTimeFormat().resolvedOptions().timeZone

  let newZone = ''
  let newLabel = ''
  let plannedTime: string | null = null

  $: zoneOptions = typeof Intl.supportedValuesOf === 'function' ? Intl.supportedValuesOf('timeZone') : [localZone]

  $: displayInstant = plannedTime
    ? (() => {
        const [h, m] = plannedTime.split(':').map(Number)
        const today = new Date($now)
        return zonedWallTimeToInstant(localZone, today.getFullYear(), today.getMonth() + 1, today.getDate(), h, m)
      })()
    : new Date($now)

  function togglePlanning(checked: boolean) {
    plannedTime = checked ? new Date($now).toTimeString().slice(0, 5) : null
  }

  function addZone() {
    if (!newZone) return
    if (($worldClocks ?? []).some((e) => e.timeZone === newZone)) return
    worldClockActions.upsert({
      id: `wc-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`,
      timeZone: newZone,
      label: newLabel || newZone,
      color: '#8b7cf6',
      order: $worldClocks?.length ?? 0,
    })
    newZone = ''
    newLabel = ''
  }

  function move(index: number, direction: -1 | 1) {
    const ids = ($worldClocks ?? []).map((e) => e.id)
    const target = index + direction
    if (target < 0 || target >= ids.length) return
    ;[ids[index], ids[target]] = [ids[target], ids[index]]
    worldClockActions.reorder(ids)
  }
</script>

<section>

  <label>
    <input
      type="checkbox"
      checked={plannedTime !== null}
      on:change={(e) => togglePlanning(e.currentTarget.checked)}
    />
    Plan a meeting time
  </label>
  {#if plannedTime !== null}
    <input type="time" bind:value={plannedTime} aria-label="Planned time" />
  {/if}

  <ul>
    {#each $worldClocks ?? [] as entry, index (entry.id)}
      <li style={`color: ${entry.color}`}>
        <span>{entry.label}</span>
        <span>{formatTimeInZone(displayInstant, entry.timeZone, { hour12: false, showSeconds: false })}</span>
        <span>{formatUtcOffsetLabel(getUtcOffsetMinutes(entry.timeZone, displayInstant))}</span>
        <span>{getRelativeDiffLabel(localZone, entry.timeZone, displayInstant)}</span>
        <button on:click={() => move(index, -1)} disabled={index === 0}>Up</button>
        <button on:click={() => move(index, 1)} disabled={index === ($worldClocks?.length ?? 0) - 1}>Down</button>
        <button on:click={() => worldClockActions.remove(entry.id)}>Delete</button>
      </li>
    {/each}
  </ul>

  <form on:submit|preventDefault={addZone}>
    <input list="zones" placeholder="Time zone (e.g. Asia/Tokyo)" bind:value={newZone} />
    <datalist id="zones">
      {#each zoneOptions as zone}
```

```typescript
import { buildGoogleCalendarLink, buildIcs } from '../core/calendar'

export function openGoogleCalendarLink(title: string, start: Date, end: Date, description?: string): void {
  const link = buildGoogleCalendarLink({ title, start, end, description })
  window.open(link, '_blank', 'noopener,noreferrer')
}

export function downloadIcs(title: string, start: Date, end: Date, description?: string): void {
  const ics = buildIcs({ title, start, end, description })
  const blob = new Blob([ics], { type: 'text/calendar' })
  const url = URL.createObjectURL(blob)
  const link = document.createElement('a')
  link.href = url
  link.download = `${title.replace(/[^a-z0-9]+/gi, '-').toLowerCase()}.ics`
  link.click()
  URL.revokeObjectURL(url)
}
```

## Features

- **Clock** — digital and analog display, 12/24-hour, optional seconds, an oversized legible typeface with a size/contrast slider.
- **World Clocks** — unlimited saved zones, each showing local time, UTC offset, and a plain-text time difference at once, plus a meeting-planner mode: pick a time and see it translated live across every saved zone.
- **Alarms** — one-off or recurring, with a volume slider, a "test this alarm now" button, and redundant firing (sound + notification, with an optional full-tab takeover) so a blocked channel can't cause a silent miss.
- **Timer & Stopwatch** — multiple concurrent countdown timers plus a stopwatch with laps, both surviving tab and browser restarts.
- **Pomodoro** — configurable focus/break durations with fully automatic phase transitions and local session stats.
- **Calendar export** — add any alarm or Pomodoro session to Google Calendar (or download an `.ics` for Outlook/Apple Calendar) with one click. No sign-in, no new permission.

## Permissions

Chronly asks for the minimum needed to do its job, and nothing else:

| Permission | Why |
| --- | --- |
| `alarms` | Schedules alarm/timer/Pomodoro wake-ups reliably, even if the extension's background process has been suspended by the browser. |
| `notifications` | Shows the system notification when an alarm, timer, or Pomodoro phase completes. |
| `storage` | Saves your alarms, timers, world clocks, and settings locally (and syncs small settings across your signed-in browsers). |
| `offscreen` (Chrome only) | Lets Chrome play the alarm sound — its background service worker has no audio API of its own. |

No `host_permissions`, no analytics SDK, no account, no server Chronly talks to.

## Why Chronly

Most clock/alarm/timer extensions are either bare-bones or unreliable — alarms that silently never fire, timers that reset when a tab closes, free-tier limits that shrink over time. Chronly is built around one bet: reliability is the feature that matters most.

- Every alarm, timer, and Pomodoro session is persisted as an absolute target time, not a running countdown in memory — so it survives the background process being suspended, the browser restarting, or your computer going to sleep.
- Alarms fire redundantly (sound and notification together) so one blocked channel doesn't mean a silent miss.
- No caps on the number of alarms, timers, or world clocks you can save.
- No tracking, no ads, no account — ever.

## Conventions

- **TypeScript everywhere.** No `any` unless you leave a comment explaining
  why it's unavoidable.
- **Explicit imports for browser APIs.** Use `import { browser } from

  anyone reading the file can see where `browser` comes from. The one
  exception is WXT's own entrypoint helpers (`defineBackground`, etc.),
  which use WXT's standard auto-import, since that's idiomatic WXT.
- **Tests live next to what they test** (`foo.ts` + `foo.test.ts`).
  `lib/core` changes should come with a Vitest unit test; component changes
  in `components/` should come with a `@testing-library/svelte` test.
- **Comments explain "why," not "what."** If a comment just restates what

- **No unrelated changes in a PR.** Keep formatting/refactor changes in
  their own PR, separate from behavior changes — it makes review much
  faster.

```markdown
# Privacy Policy

Chronly does not have an account system, does not run analytics or telemetry
of any kind, and does not send your data anywhere. This page explains
exactly what the extension does with the permissions it asks for, in plain
language, and it will always match what the open-source code actually does
— you don't have to take our word for it, you can read the source.

## What never leaves your device

Everything Chronly stores — your alarms, timers, Pomodoro sessions, world
clocks, and settings — is saved using your browser's built-in extension
storage (`chrome.storage`). Some of it is scoped to `local` (this device
only) and some to `sync` (so small settings like your theme and world clock
list can follow you to your other signed-in browser profiles, using your
browser's own sync feature — not a server we run). None of it is ever sent
to us, because we don't have a server for it to go to.

## The two exceptions, and both require you to click something first

- **"Add to Calendar."** When you choose to add an alarm or Pomodoro
  session to your calendar, Chronly either opens a prefilled Google
  Calendar event page in a new tab (a plain link — no sign-in, no API call
  made on your behalf) or generates a `.ics` file on your device for you to
  download into Outlook, Apple Calendar, or anything else. Nothing is sent
  anywhere unless you complete that action yourself in the calendar page
  that opens.
- **Two-way Google Calendar sync (planned, not in this release).** A future,
  strictly opt-in feature will let Chronly keep a calendar in sync with
  your alarms automatically. It will require you to explicitly turn it on
  in settings and grant an additional permission at that point — it will
  never be silently enabled, and declining or never turning it on will
  never affect any other feature.

## What each permission is for

| Permission | Why Chronly needs it |
| --- | --- |
| `alarms` | Lets Chronly schedule reliable wake-ups that still fire even after the browser has been idle, your laptop went to sleep, or the extension's background process was shut down to save memory. This is the mechanism that makes alarms and timers actually ring on time. |
| `notifications` | Lets Chronly show you a system notification when an alarm, timer, or Pomodoro session finishes — including when the popup isn't open. |
| `storage` | Lets Chronly save your alarms, timers, world clocks, and settings so they're still there the next time you open your browser. Nothing here is readable by websites you visit. |
| `offscreen` (Chrome only) | Chrome's background service worker has no way to play audio directly, so this permission lets Chronly briefly open a hidden, non-visible page purely to play the alarm sound when it fires. Firefox doesn't need this permission because its background page can play audio directly. |

If Chronly ever requests an additional permission (for example, when the
opt-in calendar sync above ships), it will be requested only at the moment
you turn that specific feature on, and this page will be updated to explain
it before that happens.

## Open source

All of Chronly's code is public and open to audit. If you want to verify
anything on this page, read the source rather than trust this description.
```

```markdown
# Roadmap

Chronly's first release focuses on getting the fundamentals right: clocks,
world clocks, alarms, timers, and Pomodoro sessions that are reliable and
look good. The items below are deliberately out of scope for that first
release — not because they aren't valuable, but because shipping a smaller,

If any of these sound interesting, they're genuinely open for anyone to pick

## Two-way Google Calendar sync

The first release ships a zero-permission "Add to Calendar" export (a
Google Calendar link or a downloadable `.ics` file). A deeper, opt-in
integration would let alarms and Pomodoro sessions create, update, and
delete real Google Calendar events automatically, and optionally show
upcoming Calendar events on the dashboard. This needs to be built as an
isolated module that requests its own permission only when a user turns it
on in settings — it must never be able to affect core alarm reliability for
everyone who doesn't enable it.

## Floating mini-timer overlay

An always-on-top, picture-in-picture-style countdown that stays visible
over other windows or tabs while you work, independent of the popup.
Window/PiP behavior differs meaningfully between Chrome and Firefox, so
this needs its own design pass rather than being bolted onto the existing
timer UI.

## Optional Pomodoro distraction blocker

An opt-in site blocker for focus sessions, built on `declarativeNetRequest`
so it can't be trivially bypassed from the browser console, with a
lightweight one-session allowlist exception so a legitimate site (like a
music player) can still be permitted without turning blocking off
entirely. This is a different permission footprint than the rest of the
extension, so it should stay optional and clearly separated in settings.

## Additional locales

Chronly currently ships in one language. Translating the UI strings and
adding a language switcher would make it usable for a much wider audience.

## Saved theme and background profiles

The ability to save multiple named look-and-feel presets (for example
"Work," "Night," "Weekend") and switch between them instead of reconfiguring
theme and background settings each time.

## Full-tab takeover for alarms

`AlarmRecord.fullScreenTakeover` already exists as a field and a toggle in
the Alarms UI, but firing an alarm only ever plays a tone and shows a system
notification today — the optional full-tab takeover screen described in the
design spec isn't wired up yet. It needs a small dedicated page opened via
`browser.tabs.create` when a due alarm has this flag set, with a large
dismiss/snooze UI, and should reuse the existing `reconcileFiredRecord` /
`fireRecord` flow in `entrypoints/background.ts` rather than adding a
parallel one.

## Live toolbar badge

Showing the nearest active alarm/timer's remaining time on the toolbar icon
badge (`browser.action.setBadgeText`) was part of the original design but
didn't make it into this release: the background service worker only wakes
every 30 seconds (Task 9), which isn't granular enough for a genuinely
"live" countdown badge, and a proper implementation needs a foreground page
to drive per-second updates only while one happens to be open. Worth
revisiting with a concrete UX proposal rather than a half-accurate badge.
```
