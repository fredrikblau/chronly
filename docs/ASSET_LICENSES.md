# Asset licenses

## Bundled sounds

The OGG files in `public/sounds/` come from Kenney's [Interface Sounds
pack](https://kenney.nl/assets/interface-sounds). They are released under
[Creative Commons CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The original pack license is also included beside the files.

## Screenshots and icons

The screenshots in `docs/assets/` are captures of Chronly's own UI, generated by
`npm run screenshots`. The icon files in `public/` are generated from the
project icon source in `assets/`, and the interface icons in
`components/Icon.svelte` were drawn for this project. All are covered by this
repository's MIT license.
